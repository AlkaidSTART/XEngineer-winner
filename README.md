# XEngineer-winner

本仓库用于汇总「七牛云 XEngineer 获奖作品」相关项目，方便集中查看与检索。

## 仓库结构

- `/七牛云项目/`：获奖项目目录（每个子目录对应一个项目仓库）。
- `/七牛云项目/七牛云XEngineer获奖作品链接.md`：官方获奖作品仓库链接清单（当前收录 37 个项目）。
- `/七牛云项目/clone_all.sh`：根据链接清单批量拉取项目的脚本示例。

## 使用说明

1. 直接进入 `/七牛云项目/` 浏览各项目源码。
2. 需要查看全部来源链接时，打开：
   `/home/runner/work/XEngineer-winner/XEngineer-winner/七牛云项目/七牛云XEngineer获奖作品链接.md`
3. 如需批量拉取项目，可参考 `clone_all.sh`，并先按本地环境修改脚本中的目标路径。

## 维护建议

- 新增/更新获奖项目时，优先同步更新链接清单文件。
- 若项目数量变化，请同步更新本 README 中的说明，保持信息一致。
